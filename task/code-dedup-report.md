## 🔍 提取的共享逻辑

### 1. `parse_port_arg()` - 端口参数解析
**之前**: 两个文件中各有一份完全相同的实现
**现在**: 提取到 `cli_common.rs`，两处调用

### 2. `CommonCliArgs` - 通用 CLI 参数结构体
**之前**: `main.rs` 有 `MainCliArgs`，`main-cli.rs` 有 `CliArgs`，字段几乎相同
**现在**: 统一为 `CommonCliArgs`，两处复用

### 3. `parse_common_args()` - 通用参数解析
**之前**: 两个文件中各有一套参数解析逻辑，大部分重复
**现在**: 统一解析器，支持 `-h`, `--help`, `-p`, `--port`, `-b`, `--bind`, `--auth`, `--no-auth`, `--token`

### 4. `ServerConfig` + `load_server_config()` - 服务器配置
**之前**: 两个文件中各有 `ServerConfig` 结构体和 `load_server_settings()` 函数
**现在**: 统一配置结构和加载函数

### 5. `apply_server_overrides()` - CLI 参数覆盖
**之前**: 两个文件中各有一份 `apply_cli_overrides()` 函数
**现在**: 统一为 `apply_server_overrides()`

### 6. `init_auth()` - 认证初始化
**之前**: 两个文件中各有几乎相同的认证初始化逻辑
**现在**: 提取为共享函数
