# 修复 Vitest 回归并发布 0.7.3

## 背景与目的

取消未经全量测试验证的 `v0.7.2` 工作流；修复测试环境和过期断言后，以新的补丁版本上传构建产物。

## 关联 Issue

- `docs/issues/测试/20260727-修复 Vitest 回归并重新发布.md`

## 变更内容

- 内联 `@lobehub/ui` 与 `@lobehub/fluent-emoji`，让 Vitest 通过 Vite 转换其 Node 无法直接加载的 ESM 目录导入。
- 让会话列表测试的 `react-i18next` mock 满足 `initReactI18next` 契约。
- 对齐共享插件面板、会话树 Portal 与工具展开控件的测试断言。
- 同步版本元数据到 `0.7.3`。

## 验证

| 命令 | 结果 |
|------|------|
| `npx vitest run` | 581 passed / 0 failed |
| `npm run build` | 通过 |
| `npm run typecheck:extensions` | 通过 |
| `npm run release:version:check` | 0.7.3 元数据一致 |

## 风险与回滚

仅影响 Vitest 依赖转换和测试契约；生产构建不读取 `vitest.config.ts`。若发布异常，可回滚此修复提交并从上一个稳定标签重新发布。

## 最终状态

- **部署状态:** 等待创建 `v0.7.3` 标签并完成 GitHub Release 工作流。
