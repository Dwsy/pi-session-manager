# 清理 Dashboard 回顾界面 AI-slop

> 将全屏故事式回顾重构为开发工具风格的单页周期报告，并修复 demo scoped stats 契约。

## 背景与目的 (Why)

现有回顾包含自动播放、场景进度、动态色相、光斑/噪点、成就稀有度、分享卡与拟人化旁白，信息密度低且与 Dashboard 现有视觉系统不一致。浏览器回归还发现 demo provider 忽略 `getStats(sessions)` 的 scope，导致周期报告混入全局统计。

## 变更内容概述 (What)

- 使用现有 `DashboardDialog` 重写回顾为单页、可滚动的周期报告。
- 保留总会话、消息、Token、成本、会话日期、连续会话日期、峰值小时、会话深度、项目/模型分布、最深会话和缓存占比。
- 删除故事场景、自动播放、分享卡、成就/稀有度、计数动画以及 `_recap.less` 专属氛围样式。
- 裁剪中英文回顾文案，仅保留实际运行路径使用的 key。
- 保留周/月默认关闭、年/半年默认开启、季度不自动触发的现有自动回顾逻辑。
- 修复 demo provider：`getStats(sessions)` 现在只聚合传入会话，并新增 scoped stats 回归测试。
- 保留独立的 Cmd+K 宽度回滚：`max-w-[1380px]`。

## 风险与影响评估

- 回顾不再提供故事轮播、成就稀有度和图片分享卡；这是本次主动删除的体验层。
- demo provider 的 scoped stats 行为发生修正，会让 Dashboard/Insight/Recap 在 demo 模式下更接近生产 provider 契约。
- 自动回顾周期偏好行为未被本次视觉重构改变。
- 工作区存在其他用户未提交改动，本次没有对其做回滚或整理。

## 回滚方案

- 回顾 UI 可按本次 diff 恢复 `DashboardRecapModal`、story/moments/visuals 文件和 `_recap.less` 导入。
- demo stats scope 修复可独立回滚 `src/demo/stats.ts`、`src/demo/store.ts` 和 `sessionProviders.ts` 三处变更。
- Cmd+K 宽度改动与回顾重构相互独立，可单独回滚。
