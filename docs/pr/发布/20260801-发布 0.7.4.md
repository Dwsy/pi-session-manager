# 发布 0.7.4

## 关联 Issue

- `docs/issues/发布/20260801-整合本地改动并发布 0.7.4.md`

## 变更内容

- 新增 Pi 会话 JSONL 索引技能，完善 Pi bridge 的会话检索描述和重命名语言策略。
- 重构工具调用审查面板，支持紧凑的文件与 Shell 审查体验。
- 为项目级 Pi 资源增加信任决策、来源发现和三态覆盖控制。
- 改进仪表板周导航、热力图可读性、会话树导航和用户消息全屏交互。
- 改进设置页面的更新安装、模型配置、主题、终端扫描和控件体验。
