# Pi Live 桥接工程化正确化

将 Pi Live bridge 与 PSM realtime 链路对齐 `@earendil-works/pi-*` 0.85.1，并修复 RPC、连接生命周期与 live state 的并发/归并正确性。

## 关联 Issue

`docs/issues/插件/20260910-Pi Live 桥接工程化正确化.md`

## 主要变更

- Pi 三个直接依赖统一升级到 `^0.85.1`。
- bridge 使用 canonical session id、0.85.1 types/events，并为 prompt/steer/follow-up 开启 `expandPromptTemplates`。
- Rust registry 使用唯一 RPC correlation id，并用 connection generation 防止 stale disconnect 删除 replacement session。
- WS/HTTP realtime 同步 queue/state/live event/disconnect 语义。
- 前端修正 partial state merge、entry count、streaming 与多 session connection state。
- 更新 Pi Live RPC SSOT，清除当前实现中的 Mariozechner、0.75.5、`ws-bridge.ts` 漂移引用。
