# PSM 项目图标识别插件与项目扫描白名单

> 新增内置插件 `psm-project-icons`：按常见标记文件识别项目类型，用品牌 SVG 图标替换通用文件夹图标；配套后端 `plugin_project_detect` 命令与自动授权的项目扫描白名单。

## 背景与目的 (Why)

项目列表所有目录都渲染同一个 `FolderOpen` 图标，无法区分 Rust / React / Python 项目。插件沙箱（`plugin_fs` roots）读不到项目目录，识别标记文件需要受控的扫描面。

## 变更内容概述 (What)

- 后端 `domain/project_detect.rs`：扫描白名单（sessions `cwd` 去重，自动授权）+ 顶层固定标记目录检测 + `package.json` 依赖细化 node 系 kind。
- dispatch 新命令 `plugin_project_detect`（dispatch-only，HTTP/WS 同路由），新权限 `projects:read`（默认授予，非 opt-in）。
- SDK：`PsmProjectDetection` / `PsmProjectsClient`（`ctx.psm.projects.detect`），权限清单扩展。
- 内置插件 `extensions/psm-project-icons/`：kind→simple-icons 品牌 SVG（白字品牌色圆盘，`url` avatar，非 emoji），project identity provider（priority 200，只换图标不动 label/path 行）。
- 图标几何从 simple-icons (CC0-1.0) 经 `scripts/generate-icon-table.mjs` 生成并 vendored（`iconTable.ts`），无运行时图标依赖。

## 风险与影响评估 (Risk Assessment)

- 新命令是纯读、白名单收口（未知目录不读盘）；plugin 命令目录 characterization 测试已更新锁定。
- 新增默认授予权限 `projects:read`：仅暴露固定标记目录存在性 + 派生 kind，不返回文件内容。
- 插件激活时批量检测一次并缓存，激活后新项目在重载前显示默认文件夹图标（与 psm-project-identity 相同权衡）。

## 回滚方案 (Rollback Plan)

在 Settings → PSM Plugins 禁用 `builtin.project-icons` 即回退到默认文件夹图标；后端命令无其他调用方，可整体移除。
