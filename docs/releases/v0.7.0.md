# Pi Session Manager v0.7.0

**Release date:** 2026-07-14

## Highlights

- **Branch Atlas** — Branch-aware session maps, timeline, navigation, and **replay** along the active path with semantic checkpoints (not raw JSONL noise).
- **More session sources** — Cursor and Antigravity scanning and viewer support.
- **Agent usage** — Backend collectors, provider parsers, and built-in Agent Usage plugin.
- **Pi labels & search** — Node labels in global FTS and in-session tree; `labels_only` / `content_only` filters.
- **Pi Live** — Real-time sync, sidebar/dashboard indicators, and steering RPCs.
- **Favorites plugin** — Pin sessions from a dedicated plugin view; reorder/pin plugin app views.

## Branch Atlas & replay

- Global map and timeline built on the session-branch model (replacing the older flow-only visualization).
- Replay controls in full-screen Atlas: play/pause, step, speed, progress scrub.
- Checkpoints on user turns, assistant replies, tools, forks, errors, and compaction.
- At forks, brief candidate-branch hint without switching your active branch.

## Session viewer & UI

- Denser embedded session tree and sidebar/viewer chrome.
- In-message search with scope filters and `Cmd/Ctrl+G` navigation.
- Process folding keeps `model_change` visible; compact conversation preview spacing.
- Debounced loading indicators (500ms) to avoid flashes.
- Global `Cmd/Ctrl+A` no longer steals select-all inside text fields.

## Integrations & plugins

- Pluggable tool render system; read tool path shortening with full path in tooltip.
- Code review plugin: stable tool selection and static assets; restored multi-hunk edit diffs.
- Session bridge fixes for Claude message envelopes and legacy Codex tool calls.

## Platform & architecture

- GUI single-port HTTP + `/ws` (default port 52131).
- HTTP adapter / SQLite cache / skills command module decompositions.
- Windows path and shell hardening; demo mode and cross-platform `.mjs` scripts.
- GitHub Releases / channel updater manifests; remote auth gate and HTTP+SSE transport.

## Upgrade

- Desktop: install the build for your platform from GitHub Releases (`v0.7.0`).
- CLI: replace the `pi-session-cli` binary and restart; config format unchanged.
- After upgrade, run a session scan if new sources (Cursor / Antigravity) were added.
