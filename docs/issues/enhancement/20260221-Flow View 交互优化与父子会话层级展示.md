# Issue: Flow View 交互优化与父子会话层级展示

## Goal

优化 Flow View 的交互体验，添加可拖拽的缩略图导航面板，支持缩放控制配置，并实现父子会话的层级视图展示。

## 背景/问题

来自用户 Warren 的反馈 (2026-02-19)：

1. **缩略图导航需求**：Flow View 的 "zoomed-out preview" 微面板目前不可交互，用户希望通过可拖拽对象快速导航
2. **缩放控制问题**：macOS 上的捏合手势容易导致误触，需要默认禁用缩放热键
3. **父子会话层级**：需要展示通过 fork 产生的父子会话关系的层级视图

## 验收标准 (Acceptance Criteria)

- [ ] WHEN 用户打开 Flow View，系统 SHALL 显示可交互的缩略图导航面板
- [ ] WHEN 用户在缩略图面板上拖拽，系统 SHALL 实时更新主视图的可见区域
- [ ] WHEN 用户启用缩放热键，系统 SHALL 响应 Cmd+/- 进行缩放
- [ ] WHEN 用户禁用缩放热键，系统 SHALL 忽略捏合手势和缩放快捷键
- [ ] WHERE 会话存在父子关系（fork 产生），系统 SHALL 显示层级树形结构
- [ ] IF 用户点击父会话，THEN 系统 SHALL 展开显示所有子会话分支

## 实施阶段

### Phase 1: 分析和设计
- [ ] 研究 React Flow 的 minimap 组件和自定义交互
- [ ] 设计缩略图导航面板的 UI/UX（位置、大小、样式）
- [ ] 分析会话数据结构中的父子关系字段
- [ ] 设计层级视图的展示方案（树形/缩进/连接线）

### Phase 2: 缩略图导航实现
- [ ] 集成 React Flow Minimap 或自定义缩略图组件
- [ ] 实现拖拽交互逻辑（drag to pan）
- [ ] 添加可见区域指示器（viewport indicator）
- [ ] 优化缩略图的渲染性能（简化节点、降采样）

### Phase 3: 缩放控制配置
- [ ] 在设置中添加 "启用缩放热键" 开关（默认 false）
- [ ] 修改 `main.rs` 中的 `zoom_hotkeys_enabled` 配置
- [ ] 实现前端缩放手势的拦截逻辑
- [ ] 添加缩放状态指示器（当前缩放级别）

### Phase 4: 父子会话层级视图
- [ ] 扩展后端 API 支持查询会话的父子关系
- [ ] 在 Flow View 中添加层级模式切换按钮
- [ ] 实现树形布局算法（fork 分支可视化）
- [ ] 添加父子会话的快速跳转链接

### Phase 5: 验证和优化
- [ ] 在 macOS 上测试捏合手势的禁用效果
- [ ] 测试缩略图拖拽的流畅度（60fps）
- [ ] 验证大型会话树（100+ 节点）的渲染性能
- [ ] 收集用户反馈并迭代优化

## 关键决策

| 决策 | 理由 |
|------|------|
| 缩放热键默认禁用 | 避免 macOS 捏合手势误触，提升默认体验 |
| 缩略图固定在右下角 | 符合用户习惯，不遮挡主要内容 |
| 层级视图使用树形布局 | 清晰展示 fork 分支关系，便于理解会话演化 |
