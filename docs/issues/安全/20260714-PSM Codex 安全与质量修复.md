## 关键决策

| 决策 | 理由 |
|------|------|
| raw WS 通过 `accept_hdr_async` 捕获握手 headers | 不以“raw WS 没有 Origin”绕过 gating；服务端必须明确知道 origin 是否缺失/允许 |
| terminal 请求需要 `terminal_capability: true` | capability 不是普通 authenticated RPC 的隐含副作用，显式声明便于审计 |
| 无 Origin 明确拒绝 terminal | native/非浏览器客户端不能证明受允许的 web origin，默认 fail-closed |
| 不把临时 alias 写入 Vitest 配置 | alias 能绕过本地 resolver 问题但会掩盖依赖/工具链基线问题；目标测试在 inline deps 诊断配置下通过，最终配置保持最小 |
