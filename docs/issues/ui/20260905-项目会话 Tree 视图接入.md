# Issue: 项目会话 Tree 视图接入

## Goal

把 Day / Status / Label 三种紧凑 Tree 分组放到桌面 Sidebar 的项目会话视图，而不是 Kanban App 自己的侧栏。

## 验收标准 (Acceptance Criteria)

- [x] 选中项目后，模式下拉控件出现在项目标题行右侧，位置对应 Sidebar content 内的项目头部区域。
- [x] Day / Status / Label 三种模式只渲染当前项目经过现有搜索/筛选/分页后的会话，并保持紧凑单行交互。
- [x] 三种模式的每个分组都可折叠；Status / Label 默认全部折叠，Day 默认仅当天分组展开，其余日期折叠。
- [x] Status 继续复用单值 Kanban Status；Labels 继续复用 Kanban 插件的多值 Labels SSOT，不复制存储。
- [x] Kanban App 侧栏恢复原有 WorkspacePanel；未注册项目会话扩展时仍回退到原 SessionList。
- [x] Labels 管理、会话右键 Status/Labels 分配、Agent metadata skill 保持可用。
- [x] 相关 typecheck、测试、build、git diff --check 全部通过。

## 实施阶段

- [x] 保留项目分页加载，并在折叠状态下提供 Load more 兜底。

### Phase 3: 验证

## 关键决策

| 决策 | 理由 |
|------|------|
| 新增单一 project-session view contribution | 现有 sessionListAction 只能渲染逐行按钮，appSidebarView 仅绑定 App 模式；直接让核心依赖 Kanban 会破坏插件边界。 |
| 模式控件由 Host 放在项目标题 trailing 区 | 精确匹配用户截图位置；插件只负责数据分组和渲染。 |
| 使用原生 select | 最小实现、键盘/无障碍行为可靠，不引入自定义下拉状态。 |
| 折叠状态按 mode/group 记录，项目切换时 remount | 满足默认折叠规则，同时保留同一项目内用户手动展开/收起的选择。 |
