# Issue: 收藏功能迁移为默认关闭内置插件

## Goal

移除主程序对收藏业务和收藏 UI 的直接持有，将现有收藏能力迁移为仓库内置、默认关闭的 `psm-favorites` 插件；启用插件后保留现有收藏交互和已有收藏数据。

## 当前状态

实施被阻塞。工作区已有大量未提交修改；在尝试调整 `SessionList` 时误执行了 `git restore src/components/session-list/SessionList.tsx`，导致该文件原有的未提交修改被恢复到 HEAD。必须先从用户/编辑器本地历史恢复该文件，之后才能继续。

## 已确认方案

- 完整迁移现有收藏交互
- 保留并迁移 `favorites.json`
- 先实现仓库内置插件
- 插件默认关闭
