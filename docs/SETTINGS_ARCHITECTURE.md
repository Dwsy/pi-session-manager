失败: 使用默认值```### 加载降级```typescriptasync function loadSettings(): Promise<AppSettings> {  // 1. 尝试从 Tauri FS 加载  try {    const settings = await invoke<AppSettings>('load_settings')    return SettingsService.validate(settings)  } catch (error) {    console.warn('Failed to load from Tauri FS, falling back to localStorage')  }  // 2. 降级到 localStorage  try {    const saved = localStorage.getItem(STORAGE_KEY)    if (saved) {      const settings = JSON.parse(saved)      return SettingsService.validate(settings)    }  } catch (error) {    console.warn('Failed to load from localStorage, using defaults')  }  // 3. 使用默认值  return defaultSettings}```### 保存降级```typescriptasync function saveSettings(settings: AppSettings): Promise<void> {  // 1. 尝试保存到 Tauri FS  try {    await invoke('save_settings', { settings })  } catch (error) {    console.warn('Failed to save to Tauri FS, falling back to localStorage')  }  // 2. 降级到 localStorage  try {    localStorage.setItem(STORAGE_KEY, JSON.stringify(settings))  } catch (error) {    console.error('Failed to save to localStorage', error)    throw error  }}```---## 🎯 性能优化### 1. 防抖保存```typescript//
