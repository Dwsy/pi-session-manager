Default return defaultSettings}```### Saving Fallback```typescriptasync function saveSettings(settings: AppSettings): Promise<void> { // 1. try saving to Tauri FS try { await invoke('save_settings', { settings }) } catch (error) { console.warn('Failed to save to Tauri FS, falling back to localStorage') } // 2. fallback to localStorage try { localStorage.setItem(STORAGE_KEY, JSON.stringify(settings)) } catch (error) { console.error('Failed to save to localStorage', error) throw error }}```---## 🎯 Performance Optimization### 1.
