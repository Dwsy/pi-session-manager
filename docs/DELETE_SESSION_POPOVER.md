# Delete Session Popover Implementation## Summary将删除会话确认从全屏对话框改为 popover 下拉菜单形式，减少用户鼠标移动距离，提升交互体验。同时修复了 i18n 翻译键的使用问题。## 改动文件### 新增文件- `src/components/DeleteSessionPopover.tsx` - 新的删除确认 popover 组件### 修改文件- `src/components/SessionList.tsx` - 添加 popover 状态和渲染逻辑- `src/components/kanban/KanbanColumn.tsx` - 添加 popover 状态和渲染逻辑- `src/components/app/AppOverlays.tsx` - 移除旧的对话框渲染- `src/App.tsx` - 移除删除对话框相关状态和回调## 主要改进### 1. 交互优化**修改前：**- 点击删除按钮 → 屏幕中央显示模态对话框 → 用户鼠标需要长距离移动- 阻挡整个屏幕，视觉干扰大**修改后：**- 点击删除按钮 → 按钮附近显示 popover → 鼠标移动距离最小化- 轻量级提示，视觉干扰小### 2. i18n 修复修复了翻译键的使用，现在正确显示：- 单个会话：`app.confirm.deleteSession` - "确定要删除会话 "{name}" 吗？"- 批量删除：`app.confirm.deleteSessions` - "确定要删除选中的 {{count}} 个会话吗？"- 警告提示：`app.confirm.deleteIrreversible` - "此操作无法撤销。"### 3. 路径显示优化- 单个会话：显示完整路径（灰色背景区域）- 批量删除：显示前 3 个会话名称，超出显示 "+X more"## 技术实现### DeleteSessionPopover 组件特性```typescriptinterface DeleteSessionPopoverProps {  sessions: SessionInfo[]  anchorRef: React.RefObject<HTMLElement>  // 锚点元素引用  onConfirm: () => Promise<void>  onCancel: () => void  onConfirmStart?: () => void}```### 位置计算逻辑```typescript// Position below and to the right of anchorlet top = rect.bottom + window.scrollY + 8let left = rect.left + window.scrollX// Ensure within viewportif (left + popoverWidth > window.innerWidth + window.scrollX) {  left = window.innerWidth + window.scrollX - popoverWidth - 16}if (top + popoverHeight > window.innerHeight + window.scrollY) {  top = rect.top + window.scrollY - popoverHeight - 8}```### 键盘支持- `Enter` - 确认删除- `Escape` - 取消删除- 点击外部区域 - 自动关闭## 视觉设计```┌─────────────────────────────────────┐│ ⚠️  删除会话                  ✕    ││ 确定要删除会话 "example.jsonl" 吗？ ││                                     ││ 此操作无法撤销。                     ││ ─────────────────────────────────   ││ ~/.pi/agent/sessions/.../file.jsonl ││ ─────────────────────────────────   ││           [取消]  [删除]            │└─────────────────────────────────────┘```## 兼容性- ✅ 支持单个会话删除- ✅ 支持批量会话删除（Kanban 模式）- ✅ 右键菜单删除- ✅ 列表删除按钮- ✅ 键盘快捷键操作- ✅ 移动端适配## 测试验证```bash# TypeScript 编译检查npx tsc --noEmit# 结果：0 errors ✅```## 相关文件- 翻译文件：  -
