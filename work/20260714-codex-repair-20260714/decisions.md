# Decision Points

## D1: Implementation Route

Question: Which route should the next implementation take?

- Direct implementation: scope is clear, blast radius is small, validation path is known.
- Research first: domain facts, dependencies, or ownership are unclear.
- Split into slices: work is valid but too broad for one safe change.

## D2: Cycle Outcome

Question: After Check, should this cycle close, pivot, or continue?

- Close cycle: acceptance evidence is complete and no important risk remains.
- Continue same cycle: core direction is right but more execution is required.
- Pivot plan: validation changed the problem or invalidated current assumptions.
